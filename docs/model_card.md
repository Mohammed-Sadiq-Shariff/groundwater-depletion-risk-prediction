# Future model card

This document will be completed only after a model has been trained and evaluated. It must record:

- intended use and out-of-scope uses;
- confirmed target variable and risk-class definition;
- features and feature-generation process;
- data provenance, licenses, sources, coverage, and known gaps;
- training, validation, and test periods;
- validation strategy and leakage controls;
- final model, version, and hyperparameters;
- evaluation metrics, results, and uncertainty;
- limitations, bias risks, and geographic/temporal generalisation limits;
- reproducibility details, software environment, and decision history.

No values or claims belong here until supported by actual data and experiments.
